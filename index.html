QuotaBar

Un punto de color en la barra de menús del Mac que te dice cuánta cuota de Claude te queda, y te avisa antes de que se acabe. Open source, ~900 líneas de Swift.

git clone https://github.com/romaniker/QuotaBar.git && cd QuotaBar && ./install.sh

Requisitos: macOS 14+ (Intel o Apple Silicon), Command Line Tools (xcode-select --install) y Claude Code con sesión iniciada. Se compila en tu Mac: no hay binario que descargar.

Privacidad: lee el token que Claude Code ya guarda en tu Llavero, no almacena credenciales propias y solo habla con la API de Anthropic. Sin analítica ni telemetría.
