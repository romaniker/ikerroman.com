QuotaBar

Un punto de color en la barra de menús del Mac que te dice cuánta cuota de Claude te queda, y te avisa antes de que se acabe.

Qué hace

  • Muestra en la barra de menús el porcentaje de cuota usado: verde, ámbar o rojo según lo cerca que estés del límite.
  • Al pulsarlo, una barra por límite (sesión de 5 h y semanal) con la cuenta atrás hasta que se reinicia.
  • Te notifica al cruzar los umbrales que tú elijas, una sola vez por ventana. Sin spam.
  • Distingue «0 %» de «no lo sé»: si falla la red te enseña el último dato conocido, atenuado, nunca un cero falso.

Sin ventana principal, sin icono en el Dock, sin cuenta. Es una utilidad, no una suite.

Instalar

Se compila en tu Mac en unos 20 segundos. No hay binario que descargar: no está firmado ni notarizado, y no quiero acostumbrarte a saltarte Gatekeeper con ejecutables de desconocidos.

git clone https://github.com/romaniker/QuotaBar.git && cd QuotaBar && ./install.sh

Requisitos: macOS 14 o posterior (Intel o Apple Silicon), Command Line Tools de Apple (xcode-select --install) y Claude Code con sesión iniciada.

Privacidad

QuotaBar lee el token que Claude Code ya guarda en tu Llavero (macOS te pedirá permiso la primera vez: «Permitir siempre»). No escribe en el Llavero, no pide contraseñas y no almacena credenciales propias. Habla con un único servidor, la API de Anthropic, para leer tu consumo. Sin analítica ni telemetría. El código es corto y está pensado para que lo leas.

No es un producto oficial de Anthropic.
